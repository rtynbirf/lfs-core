# ROADMAP v0.8 — Судья стратегий

Стенд не лежит на полке: аудит v0.6.1 оставил 4 открытые задачи, а мировая практика
2026 подтверждает направление. Это ТЗ следующего опровержения, не список пожеланий.

## Мировой контекст (тренды, по которым издано)

- **Динамические бенчмарки** — главный тренд агентных оценок 2026: статические миры
  агент переобучает; ответы — генерация вариаций, лог-анализ, машинные вердикты
  ([Emerging Trends in AI Agent Evaluation, Princeton, 2026](https://sage.cs.princeton.edu/trends/emerging-trends-paper.pdf)).
- Слабое место современных агентов по frontier-отчётам 2026 — **стратегическое суждение**
  (выбор между несовместимыми целями), а не исполнительская рука
  ([METR research](https://metr.org/research)).
- Pre-registration порогов — не наша экзотика, а мировая норма честной оценки;
  у нас margin=0.10 / min_pass_rate=0.90 зафиксированы с v0.7 — не трогать.
- Гигиена веса репо: GitHub норма — история это ценность, но мусор из истории
  вычищают ([about large files](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files)).

## Задачи v0.8 (все — из AUDIT.md v0.6.1, не новые)

1. **Мир несовместимых проектов.** Упорство без целей объективно недостаточно:
   ограниченный бюджет шагов, проекты конкурируют за ресурс, агент обязан ЗНАТЬ,
   какой проект умер (сейчас смерть решается эвристикой «доделай начатое»).
   Это тест на стратегическое суждение — то, где агенты слабее всего по 2026.
2. **Починить режим D.** Сброс мёртвой цели (`current_goal` держит цель вне `available`),
   содержательный пересмотр (revises>0, abandons>0 в штатном мире). Перемерить на
   `decay=True, harsh=True` — там D сейчас хуже контроля без целей (0.385 против 0.479).
3. **Одинаковая информация для всех режимов.** Убрать payoff неоткрытых проектов из
   `obs` — режим B с оракулом не может считаться «целями извне».
4. **Пороги — раз и навсегда.** v0.4.1 0.10/0.90 → v0.5 0.10/0.85 → v0.6 0.08/0.80 →
   v0.7 0.10/0.90: четыре перемены без обоснования. В v0.8 пороги менять нельзя;
   отказ от изменения — тоже факт, который фиксируется.

## Контроль честности v0.8

- **Свежие сиды** на каждом прогоне (динамический мир) — вердикт не должен
  переобучаться на конкретных эпизодах.
- **Контроль без целей** (StickyHeuristic) — базовая линия сравнения. Δ считать
  к нему, а не к A_Reactive: A намеренно близорук и завышает эффект.
- NOT_REFUTED ≠ доказано — писать в каждый вердикт, как в v0.3.
